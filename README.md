# 🎯 Guess It!

**Guess It!** is a simple yet addictive number guessing game that challenges your logic and intuition.  
Try to guess the secret number in the fewest attempts possible — each hint brings you closer to victory!

## 🕹️ Features
- Randomly generated secret number every round  
- Dynamic feedback after each guess  
- Simple, clean, and responsive UI  
- Playable on desktop and mobile  

## 🧠 Technologies Used
- HTML  
- CSS  
- JavaScript  

## 🚀 How to Play
1. Enter your guess in the input box.  
2. Click **Check** to see if your guess is too high, too low, or correct.  
3. Try to guess the number in as few attempts as possible!
